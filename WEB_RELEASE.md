# VELUM web preview

[Play online](https://acsokis.github.io/velum/), or extract this ZIP and run `RUN_WEB.cmd` with Node.js 22 or newer installed. Keep `build-web` and `tools` beside the launcher.

Click the game and press E to hatch. WASD move, mouse/drag look, Space jump, hold E gather, T tool, C upgrade, Tab terminal, F10 graphics, K/L save/load. Music starts OFF.

Early preview. Browser graphics and hardware support vary; RTX options are unavailable on web. The hosted game works without a companion.
