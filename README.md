# VELUM

A playable 3D exploration and survival prototype inside a shifting electronic labyrinth.

- [Play in your browser](https://acsokis.github.io/velum/)
- [Download for Windows](https://github.com/acsokis/velum/releases/download/v0.1.1-preview/VELUM-Windows.zip)
- [Releases](https://github.com/acsokis/velum/releases)

## Windows

Extract the ZIP and run `RUN_VELUM.cmd`. Graphics features adapt to supported hardware. Use `RUN_DX12.cmd` for the standard renderer.

## Controls

WASD move, mouse look, Shift run, Space jump, E hatch/interact/gather, T salvage tool, C upgrade, F recharge, Tab terminal, F10 graphics. Native: F5/F9 save/load. Browser: K/L save/load. Music starts OFF.

## Preview

Changing labyrinth sections, gathering, crafting, survival, weather and local saves are playable. The hosted browser game works without a companion. This is an early preview; performance and device support vary. External service integrations remain unavailable in the public preview.
